# Client-management-python

A interactive Command Line Interface (CLI) application built in Python to manage client records. This project demonstrates modular programming using custom functions, input validation, error handling, dictionaries, and list structures.

## 🚀 Features

- **User Registration:** Collects and validates client name, age, phone number, and ID.
- **Input Validation:** Handles empty entries, number ranges, and invalid data types using `try...except` and standard string methods.
- **Client Search:** Allows searching for specific registered clients by their unique ID.
- **Interactive Menu:** Clean control flow using Python's `match/case` statement.
